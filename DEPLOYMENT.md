# GitHub Pages deployment — The Tins

Public page: https://fromthetins.github.io/Fromthetins/

1. Upload this archive's index.html, sitemap.xml, .nojekyll, and the complete assets/ folder to the publishing root of the Fromthetins repository. The HTML embeds all runtime assets; no other fonts/scripts/video files are needed.
2. Enable or retain GitHub Pages for the repository's publishing branch/folder. Keep capitalization exactly as in the URL.
3. Check that the public page, sitemap and share image return HTTP 200.
4. In Google Search Console, verify ownership of the URL-prefix property https://fromthetins.github.io/Fromthetins/ and submit https://fromthetins.github.io/Fromthetins/sitemap.xml. The XML is a sitemap, not an ownership-verification file. Google must supply any HTML verification token.

## robots.txt on a GitHub project site

Google reads robots.txt only at https://fromthetins.github.io/robots.txt. A copy at /Fromthetins/robots.txt does not control crawling. If you maintain the account-root Pages site, publish the included robots.txt there. Otherwise the sitemap can still be submitted directly in Search Console; do not block it in an existing origin-root robots file.
